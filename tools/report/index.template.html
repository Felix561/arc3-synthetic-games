Studio V1 and V2 have short recorded solutions

Studio V1 and V2 each have a 6-input median completed level, compared with 15 for NVIDIA. The official human reference has a median of 54 inputs to first level completion, but those players had to discover rules that the synthetic-data agents could read in source. Source access and different players make these counts unsuitable for estimating a human difficulty gap.

Execution length and progression

Easy tutorial levels are desirable. The important question is what later actions accomplish: changed access, competing preparations and learned relations can deepen a task; extra travel or repeated local cycling can lengthen it without doing so.

There are 20 exact repeated-recipe occurrences across 18 synthetic games. Matching requires the entire input sequence and its parameters, not merely equal lengths. V208 repeats L4→L6 and L5→L7. Reuse can test transfer; a repeated late recipe is a review signal rather than proof of redundancy. The downloadable recipe table contains identities and lengths, not the action sequences.

Control coverage depends on the denominator

IDs 1–4 are directional inputs, ID5 the action button, ID6 coordinate input and ID7 the API Undo control. These labels do not identify what an input causes. A direction may move an avatar, selector or group; a click may select, probe, apply or launch.

Click-only paths cover 9/30 V1, 2/20 V2 and 14/25 NVIDIA games. Six synthetic games advertise a non-recovery modality absent from the selected path. SG01's click is a visual probe, while SG08 supports destination clicks as an alternative to arrows. Observed use and causal availability must stay separate.

Five retained NVIDIA reset controls and 1,757 official resets after initialization are counted separately from policy inputs. V2's selected export cannot supply an all-attempt reset rate.

Human reference: where players finish and stop

The available official archive contains 340 plays, 144 WINs and 183 native levels across 25 public games. ARC Prize's announcement lists 342 plays and 145 solves. The difference is G50T: 12 plays and 2 solves in the analyzed archive versus 14 and 3 in the article. No missing observations are imputed. Official human-data announcement.

ARC3's Relative Human Action Efficiency uses per-level human completion baselines and a specified aggregation method. It measures agent performance relative to those baselines, not intrinsic difficulty. No official RHAE or calibrated human-difficulty score is computed for these synthetic games. Official scoring methodology.

Variety of causal problems and visual grammar

One primary mechanical family and one visual grammar were assigned per game across the 100-game comparison. This source-informed, single-reviewer coding simplifies hybrids. It measures coverage under a disclosed taxonomy, not objective semantic distance or proven novelty.

Descriptive Jensen–Shannon divergence from the official primary-family mix is 0.155 for V1, 0.146 for V2 and 0.188 for NVIDIA, on a scale where zero is identical and one is disjoint. These small manually coded portfolios do not support a novelty ranking. Different coding could change the result.

Provisional mechanical assessments

Planning coupling, discovery burden and visual decoding are separate ordinal judgments, each from 1 to 3. Planning ranges from local adjustment through linked choices to multistage/history-dependent reasoning. Discovery concerns learning unfamiliar rules; decoding concerns reading relevant state. The ratings are source-informed hypotheses, not calibrated human scores or a weighted difficulty index.

Implications for synthetic game design

Short late-level paths and repeated recipes suggest testing designs in which earlier choices affect later steps. Longer paths or denser images alone would not address this.

  • Teach a rule through visible intervention. Separate a familiar object/spatial intuition from the unfamiliar toy rule; provide a recoverable opening experiment and a changed transfer case.
  • Make later choices consequential. Inspect what an earlier preparation changes and what must be preserved. Challenge greedy, fixed-order and repeated-recipe strategies without banning lawful shortcuts.
  • Broaden objectives and information structure. Explore learned operator composition, information that changes a plan, role-changing resources and coordination rather than recurring placement alone.
  • Audit control meaning and native visual clarity. Numeric input balance cannot certify skill balance. Check that goals, controls and object states remain clear when pieces overlap or become selected.
  • Measure discovery separately. Matched source-blind evaluation with retained failures would address questions that selected source-informed teacher paths cannot answer.

These are design inferences from the analysis, not measured effects on a learner. The ARC3 technical report provides the reference principles of core priors, introductory teaching and later composition. ARC3 technical report, §3.4.

Methods, provenance and reusable data

Frozen inputs

Synthetic data are the v2.0.0 release at source commit 86bdcda. All 75 synthetic modules were inspected as text/AST; this analysis did not import or run generated Python. The official comparison uses 25 supplied public versions and saved observations. The review covers source code and recorded observations; it does not include a new full playthrough of every game.

Action and completion accounting

Each ACTION1–7 input counts once, including blocked inputs, probes and Undo. RESET controls, passive animation frames, model reasoning and tool calls are excluded. Synthetic canonical rows have N actions and N+1 native 64×64 palette observations. All 555 rows satisfy that invariant.

Official first completions use the highest previously completed level, handling nine counter decreases and three restore jumps without counting the same level twice. Twenty-three replays begin with a real input rather than RESET; no missing initial observation is invented. Event totals reconcile with 338/340 summary footers. Two SB26 records differ by six events in total; charts use recorded events without silently replacing them with footer counts. Learning-phase statistics exclude post-WIN inputs.

Exposure and sampling

Dedicated synthetic-data actors could inspect game source and mechanics. Collection configuration requested GPT-6.1-sol, with ultra requests in the original partitions and ultra/xhigh across V2; effective model identity was not independently measured. Studio V2 retains successful level excerpts, while the earlier partitions retain full-run recordings and five NVIDIA interrupted segments. The distinct retention policies prevent a blind model-success estimate.

All 25 official replay version IDs match the supplied references; that does not prove identical historical runtime bytes. Opening visual metrics use 24 saved native RESET frames and one saved human RESET frame for KA59. A single opening per game cannot represent every later visual state.

Limitations

No new full playthrough, human study, seed sweep, minimum-action proof, random-policy resistance test or held-out transfer experiment was performed for this analysis. Difficulty and novelty assessments are nonblind and provisional. Neither this report nor its action counts establish learner improvement or generalization to unseen benchmark games.
